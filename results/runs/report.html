5 case tệ nhất (đoán nguyên nhân + đề xuất):

  1. Shirt → T-shirt/top (95): hình dáng gần như giống hệt ở 28×28 → augmentation shift/rotation nhẹ.
  2. T-shirt/top → Shirt (90): cùng nhóm áo cổ tròn tay ngắn → label smoothing.
  3. Shirt → Pullover (64): tay dài/thân rộng lẫn lộn → thêm mẫu khó hoặc class weight nhóm áo.
  4. Coat → Pullover (63): chất liệu/dáng khoác tương tự → tăng độ sâu kênh conv nếu có GPU.
  5. Coat → Shirt (55): cổ/vạt áo gây lẫn → GradCAM kiểm tra vùng model nhìn.

7. Limitations + Next steps

  • Chưa có demo 1 lệnh (src/demo.py) và chưa đo latency live từng mẫu.

Next steps (3):
